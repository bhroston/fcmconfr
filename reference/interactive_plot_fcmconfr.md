# (Interactive) Plot fcmconfr

Load plot of fcmconfr output in an interactive shiny window

## Usage

``` r
interactive_plot_fcmconfr(x, ...)
```

## Arguments

- x:

  A direct output of the
  [`fcmconfr`](https://bhroston.github.io/fcmconfr/reference/fcmconfr.md)
  function

- ...:

  Additional inputs:

  - filter_limit Remove concepts whose inferences do not exceed this
    value

  - coord_flip Swap x- and y-axes (i.e. rotate plot)

## Value

A shiny window displaying a plot of an fcmconfr object's results

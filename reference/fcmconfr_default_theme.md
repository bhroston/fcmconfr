# Default plot.fcmconfr Theme

A formal call to the custom_theme defined by
[`fcmconfr_theme_custom`](https://bhroston.github.io/fcmconfr/reference/fcmconfr_theme_custom.md)

## Usage

``` r
fcmconfr_default_theme()
```

## Value

A default ggplot2 theme for fcmconfr plot objects
